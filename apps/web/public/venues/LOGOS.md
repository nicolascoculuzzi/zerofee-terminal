# Platform logos

Each file is the platform's own site icon (or the logo it publishes on-chain), resized to a 64 px WebP by
`apps/web/scripts/fetch-venue-logos.ts` (raster sources only; no third-party SVG is bundled). They are used
only to identify the platform a token launched or trades on, at 12-16 px. The names and logos are trademarks
of their owners; zerofee is not affiliated with or endorsed by any of them.
